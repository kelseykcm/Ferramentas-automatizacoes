Este repositório contém uma coleção de ferramentas e scripts de automação dedicados à cibersegurança, engenharia reversa, hacking ético e inteligência de ameaças. Projetado para profissionais de segurança, pesquisadores e entusiastas, oferece recursos modulares para diversas áreas de cibersegurança.

## 📁 Estrutura do Projeto

O projeto está organizado em diretórios temáticos para facilitar a navegação e o uso:

- **C&C**: Ferramentas para comando e controle de bots, implantes e comunicações seguras em cenários de teste.
- **Criptografia**: Implementações de algoritmos criptográficos, ferramentas de quebra e análise de cifras.
- **CTI**: Recursos para Cyber Threat Intelligence, incluindo coleta, análise e visualização de inteligência de ameaças.
- **DarkWeb**: Scripts para monitoramento, scraping e análise de conteúdo na Dark Web.
- **Engenharia_reversa**: Ferramentas para desmontagem, debugging e análise de binários e malware.
- **Exploracao**: Exploits, payloads e frameworks para exploração de vulnerabilidades.
- **H4C3R**: Coleção de ferramentas personalizadas para operações de hacking ético (H4C3R).
- **Hacking-Hardware**: Recursos para hacking de hardware, IoT e dispositivos embarcados.
- **Hacking-Networking**: Ferramentas de análise de rede, sniffing, spoofing e ataques de rede.
- **Hacking-Web**: Scripts para pentests web, SQLi, XSS, CSRF e automação de scanners.
- **Inteligência Artificial e ML**: Modelos de IA e Machine Learning aplicados a detecção de anomalias e análise de malware.
- **LLMs e Reconhecimento**: Uso de Large Language Models para automação de reconnaissance e OSINT.

Cada diretório inclui READMEs individuais com instruções de uso, dependências e exemplos.
